# WiFi Translator (Android)

مشروع أولي بـ Python + Kivy لاكتشاف أسماء شبكات Wi-Fi القريبة، اختيار شبكة،
تطبيق قواعد التحويل التي زودني بها المستخدم، ونسخ النتيجة أو فتح إعدادات Wi-Fi.

## قواعد التحويل
- `fh_` -> `wlan` (تُطبق أولاً)
- `a` -> `5`
- `d` -> `2`
- `b` -> `4`
- `f` -> `0`
- `8` -> `7`
- `9` -> `6`

## مهم
التطبيق لا يستخرج كلمة مرور Wi-Fi ولا يستطيع استنتاجها من SSID. النتيجة
مجرد تحويل نصي حسب القواعد المدخلة، ولن تكون كلمة المرور صحيحة إلا إذا كانت
هذه القواعد مطابقة فعلاً لطريقة إعداد كلمة مرور الشبكة.

Android يقيّد فحص الشبكات. قد تتطلب النتائج أذونات الموقع/الأجهزة القريبة
وتشغيل خدمات الموقع، كما قد يعيد النظام نتائج مخزنة أو يحد من تكرار الفحص.
التطبيق لا يحاول تجاوز هذه القيود. تشغيل/إيقاف Wi-Fi مباشرة غير متاح عادةً
للتطبيقات العادية على Android الحديث؛ لذلك يفتح التطبيق صفحة إعدادات Wi-Fi
ليتحكم المستخدم بنفسه.

## الملفات
- `main.py`: واجهة Kivy ومنطق الفحص والتحويل.
- `buildozer.spec`: إعدادات بناء APK.

## البناء
يفضل البناء على Linux أو WSL:
1. تثبيت Buildozer ومتطلبات Android SDK/NDK حسب دليل Buildozer الرسمي.
2. من مجلد المشروع شغّل:
   `buildozer android debug`
3. سيظهر ملف APK داخل مجلد `bin/`.

ملاحظة: إعدادات SDK/NDK قد تحتاج مواءمة حسب نسخة Buildozer وبيئة البناء.
لا يمكن بناء APK من هذا الملف وحده دون بيئة Android SDK/NDK.

## التوافق
الإعداد الحالي يستهدف Android 12 / API 31 فما فوق. فحص Wi-Fi يعتمد على
قيود النظام وإعدادات الجهاز والشركة المصنّعة.
